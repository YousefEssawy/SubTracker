# Quickstart: Mobile Design Refactor

## Getting Started

Because this is a layout and design feature, standard node execution applies.

1. Ensure packages are installed via `npm install`
2. Start the Vite server using `npm run dev`
3. Navigate to `http://localhost:5173/SubTracker/`
4. The unauthenticated landing page should appear.

## Layout Assessment

- View the page on Desktop (>768px). Sidebar should be docked.
- View the page on Mobile (<768px). The sidebar should transform into an accessible hamburger menu with no visible bottom navigation bar.
- Open the Chrome developer tools and set the viewport to exactly `320px` width. Validate the absence of any horizontal scroll bars.
